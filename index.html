ALRM 技术™

独家 NAAP™ · C++
NAAP (New Architecture App Nap) 是 NVazen 团队开发的独家 App Nap 技术：窗口被最小化或完全遮挡时，进程就地冻结（cgroup v2），重新聚焦的瞬间立即解冻——应用原地待命，后台功耗大幅降低。作为 ALRM / ALPRM 技术线的后继，NAAP 采用呼吸式循环（冻结 200 ms + 解冻 50 ms），保证 D-Bus 与 IPC 调用响应不超过约 250 ms；内置崩溃恢复（SIGTERM 解冻 + 启动扫描）与基础设施黑名单，稳定又安全。NVazen Linux 滚动版已搭载 NAAP 引擎。

App Nap

窗口最小化或被完全遮挡时，进程被 cgroup.freeze 就地冻结；重新聚焦瞬间解冻。后台应用停止消耗 CPU，而一切保持原样。

快速响应

呼吸式循环在 200 ms 冻结与 50 ms 解冻之间交替，桌面服务、菜单与 D-Bus 调用始终在约 250 ms 内得到响应——菜单不卡顿、操作无迟滞。

崩溃恢复

即使桌面意外崩溃，NAAP 也会在 SIGTERM 时解冻全部应用，并在启动时执行恢复扫描，绝不让任何应用被遗留在冻结状态。

安全过滤

基础设施黑名单保护 KWin、Plasma Shell、D-Bus 与 PipeWire 不被冻结；窗口可见性按 PID 聚合——同一应用的多个窗口全部隐藏时才会冻结。
