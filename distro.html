❓ 这是什么？

这是一个简约的 Linux 发行版目录页，用于集中展示各个发行版的基本信息与详细介绍。点击任意卡片即可查看该发行版的介绍文档。

如何提交你的发行版？

  1. 前往 GitHub 仓库 Distro-list（由本站维护者创建）。
  2. 进入仓库中的 distro 目录。
  3. 新建一个文件，命名为 about-发行版名字.txt 或 about-发行版名字.md，在里面写你的发行版介绍。
  4. 提交 Pull Request 或直接提交（取决于仓库权限）。

然后呢？

维护者会在有空时查看你的提交。由于是人工审核，可能需要等待较长时间，请耐心等待。通过后你的发行版会出现在本列表中。

注意

  • 请使用清晰的发行版名称，避免重名或误导。
  • 介绍内容请保持真实、简洁，不要包含恶意链接。
  • 建议同时提供发行版图标（PNG 格式），以便在卡片中展示。
